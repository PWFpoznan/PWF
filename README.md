# Poznańskie Warsztaty Filmowe (PWF)

Oficjalna strona internetowa Poznańskich Warsztatów Filmowych.

## Technologie
* HTML5 / CSS3 / JavaScript
* Hosting: Netlify

## Struktura projektu
* `index.html` - Strona główna
* `regulamin.html` - Regulamin warsztatów
* `polityka-prywatnosci.html` - Polityka prywatności
* `robots.txt` - Instrukcje dla robotów wyszukiwarek
